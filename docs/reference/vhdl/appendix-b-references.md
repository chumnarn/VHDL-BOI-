# ภาคผนวก B: แหล่งอ้างอิง

> รายการอ้างอิงแบบมีรหัสสำหรับอ้างถึงข้ามบท เช่น "ดู [STD-01]" หรือ "ตรวจคำสั่งใน [TOOL-02]"
> ทุกลิงก์ด้านล่างถูกตรวจสอบว่าเข้าถึงได้จริง ณ วันที่ระบุ แต่หน้าเว็บแต่ละแห่งเปลี่ยนได้
> **ให้ผู้เรียนตรวจสอบเวอร์ชันล่าสุดเองทุกครั้งที่อ้างอิง**

**วันที่ตรวจสอบลิงก์:** 1 ธันวาคม 2026

---

## B.1 วิธีเลือกแหล่งอ้างอิงตามประเภทคำถาม

| ประเภทคำถาม | แหล่งอ้างอิงหลัก | รหัส |
|---|---|---|
| ความหมายของคำในภาษา VHDL | เอกสาร LRM ของ IEEE | [STD-01]–[STD-03] |
| ความหมายของฟีเจอร์ VHDL-2008 | LRM ของ IEEE 1076-2008 | [STD-01] |
| Syntax และตัวเลือกของคำสั่ง | เอกสารของ GHDL รุ่นที่ติดตั้ง + `ghdl --help` | [TOOL-01]–[TOOL-04] |
| ข้อจำกัดเฉพาะของเครื่องมือ | release note และ issue tracker ของเครื่องมือ | [TOOL-01]–[TOOL-04] |
| มาตรฐานของ Verilog และ SystemVerilog | เอกสาร LRM ของ IEEE และ Accellera | [STD-04]–[STD-05] |
| แนวทางออกแบบ RTL และ CDC | ตำราและบทความต้นฉบับ | [BOOK-01]–[BOOK-04] |
| ข้อกำหนดของโปรเจกต์ในคอร์สนี้ | ไฟล์ใน repository | [REPO-01]–[REPO-04] |

> **หลักการ:** เมื่อแหล่งข้อมูลขัดกัน ให้ตรวจก่อนว่ากำลังกล่าวถึงเวอร์ชันและขอบเขตเดียวกันหรือไม่
> และให้ยึดข้อกำหนดของเครื่องมือที่ติดตั้งจริงในเครื่องเป็นหลัก

## B.2 มาตรฐานภาษา (Standards)

### [STD-01] IEEE 1076-2008 — VHDL Language Reference Manual

IEEE. https://standards.ieee.org/ieee/1076/5693/

**หัวข้อที่ควรอ่าน:** บทที่ 9 (การประกาศแบบ concurrent และ sequential),
บทที่ 11 (ชนิดข้อมูลและแพ็กเกจมาตรฐาน), บทที่ 14 (subprogram และ wait statement),
บทที่ 16 (ฟีเจอร์ใหม่ของ VHDL-2008 เช่น `process (all)`, conditional expression,
`to_hstring`, `std.env`)

**ใช้ประกอบ:** บทที่ 1, 2, 3, 13
**ข้อควรระวัง:** มาตรฐานนี้ใหญ่และเข้าถึงได้ฟรีผ่านโปรแกรม IEEE Get
ให้ใช้เมื่อจำเป็นจริง ไม่ต้องอ่านทั้งเล่มเพื่อแก้ปัญหาเฉพาะจุด

### [STD-02] IEEE 1076-2002 — VHDL Language Reference Manual (VHDL-2002)

IEEE. https://standards.ieee.org/ieee/1076/10360/

**หัวข้อที่ควรอ่าน:** ส่วนที่ต่างจาก VHDL-2008 — เพราะ ModelSim ของห้องเรียนตั้ง
`VHDL93 = 2002` คู่มือนี้จึงต้องไม่ใช้ฟีเจอร์ของ VHDL-2008 ในโค้ด RTL และ testbench

**ใช้ประกอบ:** บทที่ 1, 3, 10, 13
**ลิงก์ช่วยเหลือ:** เมื่อต้องการยืนยันว่า "รูปแบบนี้ใช้ได้ใน VHDL-2002 หรือไม่"
ให้เปิด LRM รุ่นนี้ค้นหาคำที่เกี่ยวข้อง

### [STD-03] IEEE 1076-2019 — VHDL Language Reference Manual (ฉบับล่าสุด)

IEEE. https://standards.ieee.org/ieee/1076/7338/

**หัวข้อที่ควรอ่าน:** ภาคผนวกที่เพิ่มเติมจาก VHDL-2008

**ใช้ประกอบ:** อ้างอิงเชิงข้อมูลว่ามาตรฐานปัจจุบันเป็นรุ่นใด
**ข้อควรระวัง:** คู่มือนี้ยึด VHDL-2008 เป็นมาตรฐานหลัก ไม่ใช้ฟีเจอร์ของรุ่น 2019

### [STD-04] IEEE 1364 — Verilog Language Reference Manual

IEEE. https://standards.ieee.org/ieee/1364/

**หัวข้อที่ควรอ่าน:** ส่วนที่เกี่ยวกับการกำหนดค่าแบบ blocking / non-blocking
และกฎของการอ่านค่าเก่าในบล็อก `always`

**ใช้ประกอบ:** บทที่ 14
**ข้อควรระวัง:** เวอร์ชันที่ต่างกัน (1364-1995, 1364-2001, 1364-2005)
มีความต่างเล็กน้อย ให้ยึดรุ่นที่เครื่องมือของห้องเรียนรองรับ

### [STD-05] Accellera — Available IEC/IEEE Standards

Accellera Systems Initiative. https://www.accellera.org/downloads/ieee

**หัวข้อที่ควรอ่าน:** รายการมาตรฐาน HDL ที่ให้ดาวน์โหลดฟรีผ่านโปรแกรม IEEE Get
รวมถึง SystemVerilog (IEEE 1800)

**ใช้ประกอบ:** บทที่ 14
**ข้อควรระวัง:** หน้านี้เปลี่ยนโครงสร้างเป็นระยะ ให้ค้นหาจากหน้าแรกของเว็บไซต์
ถ้าลิงก์ย่อยไม่ทำงาน

## B.3 เครื่องมือ (Tools)

### [TOOL-01] GHDL — เว็บไซต์และเอกสาร

GHDL project. https://ghdl.github.io/ghdl/

**หัวข้อที่ควรอ่าน:** หน้าเอกสารประกอบการใช้งาน
([การจำลอง](https://ghdl.github.io/ghdl/using/Simulation.html),
[การสังเคราะห์](https://ghdl.github.io/ghdl/using/Synthesis.html),
การติดตั้งและการเลือก backend)

**ใช้ประกอบ:** บทที่ 12, 13, 15 และทุกบทที่มีคำสั่งของ GHDL
**หลักฐานที่ควรเก็บ:** รุ่นที่ใช้ (`ghdl --version`) และ backend
ที่เลือก (mcode, llvm, gcc) เพราะผลของการสังเคราะห์อาจต่างกันเล็กน้อย
**ข้อควรระวัง:** ตัวเลือกของ GHDL ต่างกันระหว่างรุ่น ให้ตรวจ `ghdl --help`
และหน้าเอกสารของรุ่นที่ติดตั้งก่อนใช้ตัวเลือกใด ๆ

### [TOOL-02] GHDL — ซอร์สโค้ดและ issue tracker

GHDL project. https://github.com/ghdl/ghdl

**หัวข้อที่ควรอ่าน:** release note ของแต่ละรุ่น และ issue ที่เกี่ยวกับ
ข้อจำกัดของ `--std=02` และ `-fsynopsys`

**ใช้ประกอบ:** เมื่อพฤติกรรมของ GHDL ไม่ตรงกับเอกสาร
**ข้อควรระวัง:** issue อาจถูกปิดไปแล้ว ต้องอ่านสถานะปัจจุบันเสมอ

### [TOOL-03] Icarus Verilog

Icarus Verilog. https://steveicarus.github.io/iverilog/

**หัวข่ายที่ควรอ่าน:** การใช้ Verilog ในคอร์สนี้ โดยเฉพาะข้อจำกัดของ
Verilog-2001 ที่คอร์สใช้เป็นฐาน

**ใช้ประกอบ:** บทที่ 14
**หลักฐานที่ควรเก็บ:** `iverilog -V`

### [TOOL-04] Yosys

YosysHQ. https://yosyshq.readthedocs.io/projects/yosys/en/latest/

**หัวข้อที่ควรอ่าน:** frontend ของภาษา, `synth`, `stat`, `write_verilog`
และคำสั่งสำหรับตรวจว่าโค้ดอยู่ใน synthesis subset หรือไม่

**ใช้ประกอบ:** บทที่ 10
**ข้อควรระวัง:** จำนวนเซลล์ที่ได้เป็นเพียงหลักฐานว่าเครื่องมือทำงาน
ไม่ใช่หลักฐานว่าฟังก์ชันถูกต้อง

## B.6 ข้อควรระวังเรื่องการอ้างอิง

1. **อย่าอ้างว่า "ผ่านมาตรฐานโรงงาน"** ให้ใช้คำว่า
   "ผ่านเงื่อนไขของ flow ที่ใช้ใน Lab" แทน (ดู [REPO-04])
2. **ระบุเวอร์ชันเสมอ** เมื่ออ้างอิงพฤติกรรมของเครื่องมือ
3. **คำสั่งทุกคำสั่งต้องรันได้จริง** บนเครื่องมือที่ระบุ
   ถ้าเขียนคำสั่งจากความจำ ต้องทดสอบก่อนนำไปใส่ในคู่มือ
4. **ลิงก์ภายนอกต้องตรวจแล้วว่าเปิดได้** และต้องมีวันที่ตรวจสอบกำกับ
5. **ห้ามอ้างอิงเอกสารที่ไม่มีอยู่จริง** เพราะผู้เรียนจะเสียเวลาตามหา
